// MARIE program - Sensor Reading 12 bits/ms
// Store 10 elements from Sensor 1 and compute average

// Part 1: Store elements in memory
Load Addr // We load the address of the first element
Store Next // Create a pointer

Loop, Input
Store Temp // User enters input and MARIE stores it

// Read sensor data
// Check SEL (bit 15): If SEL = 0, then sensor 1
Load Temp
SkipCond 000
Jump Extract
Jump Loop

Extract, Load Temp
Subt Limit // It enables us to use only the 12 bits of data
SkipCond 000
Jump Reduce
Jump Save

Reduce, Store Temp // Until it can be stored in 12 bits
Jump Extract

Save, Load Temp // Send it to memory
Store Value
StoreI Next // Store the AC value in the address of Next

// Go to the next position in memory
Load Next 
Add One
Store Next 

Load Count // Count = 0, declared below
Add One // Add one for each element to know how many we have (counter increases)
Store Count

Load Sum // Load the remainder from the previous reading
Add Value
Store Sum

// Part 2: Update the quotient and remainder after each reading
Divide, Load Sum
Subt Elements // Subtract the divisor
Skipcond 000 // If negative, finish this division
Jump Continue
Jump CheckCount

Continue, Store Sum // Here to avoid negative values
Load Quotient
Add One
Store Quotient
Jump Divide

CheckCount, Load Count // Check if all elements have been stored
Subt Elements // Subtract the required number of readings
SkipCond 400 // If zero, skip the jump back to Input
Jump Loop // If not 0, it continues

Final, Load Quotient
// Show the integer part of the average
Output
Load Sum
// Show the decimal digit of the average
Output
Halt

Addr, HEX 200 // Keep measurements separate from instructions and variables
Next, HEX 0
Temp, DEC 0
Value, DEC 0
Count, DEC 0
One, DEC 1
Elements, DEC 10 // Number to be stored in memory and divisor
Sum, DEC 0 // Remainder carried over to the next reading
Quotient, DEC 0 // Accumulated integer average
Limit, DEC 4096 // Considering a 12-bit sensor
